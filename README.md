# Beth Lindenbaum | Personal Portfolio

My personal portfolio website, showcasing my background, technical experience, and projects across hardware, embedded systems, and software development.

**[Visit my website](https://bethlindenbaum.github.io/personal-website/)**

## About the Site

- **About Me:** My education, experience, and interests.
- **Projects:** An overview of my technical work, with individual project pages.
- **Professional Links:** My GitHub, LinkedIn, and downloadable resume.

## Featured Projects

- **Pac-Man:** An FPGA-based game using Verilog, MIPS assembly, and a VGA display.
- **Audio-Visual Alert System for Drone Delivery:** A device that helps bystanders locate drone-delivered items through audio and visual alerts.
- **Cache Simulator:** A Java simulation of data transfer between a CPU, memory, and caches.
- **Calculator App:** An iOS app for numerical computations.
- **16-bit MIPS CPU:** A processor built in Logisim with a MIPS-based instruction set.
- **MovieMatch:** A website for finding movies to watch with friends.
