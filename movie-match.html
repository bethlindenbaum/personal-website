MovieMatch

A full-stack web app for finding a movie everyone wants to watch

View the source code on GitHub

Overview

Choosing a movie with friends often means searching several streaming services, comparing tastes, and trying to remember what everyone has already suggested. I built MovieMatch to bring that process into one place. Each person creates an account, records their streaming services and favorite genres, joins a group, and selects movies they would be happy to watch. MovieMatch then compares everyone's choices and recommends the strongest group match.


The app combines a responsive browser interface with a Supabase backend and live movie data from TMDB. It supports persistent accounts, friends, groups, personal watchlists, realtime group selections, streaming availability, and recommendations tailored to the people currently choosing together.

MovieMatch narrows a live movie catalog to the services a group can access, then ranks the results around their shared interests.

Features

Personalized Discovery

Popular, top-rated, new-release, and personalized rows make it easy to browse movies that fit the current group's genres and services.

Friends and Groups

Users connect by username and create movie-night groups, giving every group its own members and shared selection history.

Group Matching

The app compares every member's picks, finds unanimous choices, and uses group preferences and ratings to break ties.

Realtime Updates

Selections update across devices as group members add or remove movies, keeping everyone in sync during the decision.

Streaming Availability

Movie results are filtered using the group's streaming subscriptions, with regional provider data supplied by JustWatch through TMDB.

My List

Each account has a private watchlist for saving interesting movies without adding them to a group's current choices.

How Matching Works

1Set preferencesMembers choose genres and streaming services.
2Select moviesEach person saves the titles they want to watch.
3Compare picksMovieMatch finds the intersection of every member's list.
4Choose a winnerShared picks are ranked by group tastes and TMDB rating.

A unanimous selection always takes priority. If the group shares several choices, MovieMatch scores those movies using the members' preferred genres and each movie's TMDB rating. If no movie has been selected by everyone yet, the app shows the title with the most support as the group's closest current match.

Application Architecture

Browser App Responsive interface, discovery, lists, groups, and matching
↔
Supabase Authentication, Postgres, Row Level Security, and Realtime
↔
TMDB Edge Function Movie metadata, recommendations, and watch providers

The browser uses Supabase Auth for email and password accounts and stores profiles, friendships, groups, selections, and personal lists in Postgres. A server-side Edge Function makes TMDB requests, so the TMDB credential never appears in browser code. It returns current movie details, artwork, cast, ratings, genres, and regional provider availability to the interface.

Data and Security

I designed the database around separate records for profiles, friendships, groups, group membership, movie selections, and personal lists. Database functions handle multi-step operations such as adding a friendship in both directions and creating a group with its initial members. Supabase Realtime publishes changes to group selections so the browser can refresh the active group when another member makes a choice.


Row Level Security enforces ownership at the database layer: users can update only their own profile, personal lists remain private, group data is visible only to members, and users can add or delete only their own selections. The browser receives only Supabase's publishable key; the private TMDB token stays in the Edge Function's server-side environment.

Built With

  • HTML, CSS, and JavaScript — the responsive interface, client-side state, recommendation scoring, and group-matching experience.
  • Supabase Auth and Postgres — accounts and persistent data for profiles, friendships, groups, selections, and personal lists.
  • Supabase Realtime — live synchronization of movie selections across group members' devices.
  • Supabase Edge Functions — a secure server-side layer between the browser and the movie API.
  • TMDB API — current movie metadata, posters, ratings, genres, cast, and watch-provider data.
